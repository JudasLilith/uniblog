### How to run locally

> [!NOTE]
> This website was made using npm verision 10.9.8.

> [!WARNING]
> The css animation for the scroll opacity timeline is based on your browser's support of scroll driven animations. This means FireFox can only use this when explicitly said to do so. you can find more information [here](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Scroll-driven_animations)

1. git clone this repository

```bash
git clone https://github.com/JudasLilith/uniblog
```

1. run this command to install all the packages I've used:

```bash
npm install
```

1. after everything's loaded, run:

```bash
npm start
```

to start the server, and then go to <http://localhost:3000/> to check the files.

1. Happy editing!
